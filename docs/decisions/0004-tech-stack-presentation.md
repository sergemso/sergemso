## Motivation

Show depth and breadth across domains without using visual badges (which can appear junior) or a flat list (which loses domain context).

## Context

The profile covers 5 domains: AI/Agent Engineering, Backend/Platform, Cloud/Infrastructure, Frontend/Full Stack, Observability/Quality. Each has 8-10 technologies.

## Tradeoffs

- Pro: Demonstrates T-shaped skills (broad + deep in AI/Backend)
- Pro: Allows senior engineers to quickly assess fit
- Pro: More credible than badge walls
- Con: Requires more vertical space
- Con: Proficiency is self-reported, not verified

## Decision

Group by domain with inline code formatting. No explicit proficiency levels (beginner/expert) — the categorization implies primary vs secondary domains. Order domains by relevance to brand (AI/Backend first).
