## 🚀 Featured Projects

### [virage](https://github.com/vivantel/virage) — RAG Pipeline That Grows With Your Codebase
> *TypeScript/Rust · 1.2M+ LOC indexed · Production-grade*

The RAG pipeline that indexes once and stays in sync with every commit. Powers agent memory for AI coding assistants. Built with incremental AST-aware indexing, hybrid search (semantic + keyword), and eval-driven quality gates.

**Stack:** TypeScript, Rust, Tree-sitter, PostgreSQL/pgvector, GitHub Actions

### [kms](https://github.com/vivantel/kms) — Knowledge Management for AI Agents
> *Shell/Python · Plugin for Claude Code, Codex, Kilo*

Gives AI coding agents durable, checkable knowledge — decisions, facts, and guardrails they won't forget, contradict, or re-litigate. Implements ADR/decision records, fact extraction, guardrail enforcement, and skill composition.

**Stack:** Shell, Python, Markdown, Git

### [edap_model](https://github.com/sergemso/edap_model) — Endogenous Dissipation of Adaptive Potential

Mathematical model of civilization dynamics simulating how elite resource extraction erodes cooperation and technology, trapping societies in feudal equilibrium. Addresses Fermi Paradox via Great Plateau/Filter hypothesis.

**Stack:** Python (JAX/CUDA), TeX, NumPy/SciPy, Matplotlib

## 💭 Engineering Philosophy

> **Agent-Driven Development** — AI agents as first-class team members, not autocomplete. Durable context > prompt engineering.

> **Knowledge as Infrastructure** — Decisions, facts, and guardrails are versioned, reviewable, and enforced — same as code.

> **Pragmatic Craft** — Ship iteratively. Measure what matters. Optimize for change. Technical excellence serves product outcomes.

> **Systems Thinking** — Local optimizations fail. Model the whole: data flow, team topology, incentive structures, failure modes.
